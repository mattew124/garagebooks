{{ 'Change the app registration' if account and account.client_id else 'Set up' }}

Once per installation, about 10 minutes. Any Microsoft account can register the app, with no paid Azure subscription; the account that matters is the one you sign in with at Connect OneDrive or Connect mailbox, whose drive or mailbox is used. Use a new registration for this app rather than reusing one made for something else.

  1. Open the Microsoft Entra admin center (Identity → Applications → App registrations) and choose New registration.
  2. Name: anything, e.g. garagebooks.
  3. Supported account types: Personal Microsoft accounts only (“any organizational directory and personal Microsoft accounts” also works).
  4. Redirect URI: choose the platform Web and enter exactly this address, then Register: {{ new_callback_url }} It must match character for character. Microsoft only accepts http:// for localhost. A newly added address can take a few minutes to take effect: if connecting shows “invalid request” straight after adding it, wait a few minutes and try again.
  5. Authentication: leave Allow public client flows at No (the default). With it on, Microsoft treats the app as a public client and every later sign-in refresh fails with AADSTS90023: Public clients can't send a client secret.
  6. API permissions (optional): Add a permission → Microsoft Graph → Delegated permissions, tick Files.ReadWrite, Mail.Read, User.Read and offline_access. Skip it and you're asked to consent to them when you connect: OneDrive asks for the first, the mailbox for the next two.
  7. Certificates & secrets → Client secrets → New client secret. Copy its Value straight away. It's shown only once, and the Secret ID beside it is not the secret. Secrets last at most 24 months: note the Expires date for the box below.
  8. From Overview, copy the Application (client) ID (not secret).
  9. Paste both here and save, then press Connect OneDrive or Connect mailbox below.
